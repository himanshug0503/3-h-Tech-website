# 3-h-Tech-website (MERN + Vite)

## Setup
1. Install backend deps: `npm install --prefix backend`
2. Install frontend deps: `npm install --prefix frontend`
3. Copy `backend/.env.example` to `backend/.env`
4. Copy `frontend/.env.example` to `frontend/.env`
5. Run both: `npm run dev`

## Notes
- UI kept aligned with the original design.
- Dynamic content is served from backend APIs.
- Contact form posts to backend and stores in MongoDB when available.
